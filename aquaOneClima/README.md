# aquaOne Clima

Podstawowy szkielet projektu PlatformIO należącego do rodziny **aquaOne**.

## Stan
Projekt startowy bez logiki urządzenia.

## Założenia
- ESP32-S3
- Arduino Framework
- monitor portu szeregowego: 115200
- docelowo integracja ze wspólnym `aquaOneCore`

## Struktura
- `src/` — kod programu
- `include/` — pliki nagłówkowe
- `lib/` — lokalne biblioteki
- `test/` — testy
