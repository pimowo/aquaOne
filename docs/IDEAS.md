# Ideas

Ten dokument zawiera wyłącznie niezatwierdzone pomysły i backlog koncepcyjny.

Nic zapisane tutaj nie jest wymaganiem architektonicznym ani planem realizacji. Po
zatwierdzeniu pomysł MUSI zostać przeniesiony do [ROADMAP.md](ROADMAP.md) albo do właściwego
standardu technicznego.

Rozważyć przyszły wspólny standard obejmujący Web auth, secret handling, backup credentials,
onboarding AP security, MQTT auth/TLS, remote exposure, OTA signing oraz CSRF/origin/rate
limiting. Nie jest to zatwierdzony kontrakt ani pozycja Roadmap.
